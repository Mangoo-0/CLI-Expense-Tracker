# CLI Expense Tracker

A beginner-friendly command-line expense tracker built with Python.

## Features
- Add expenses with a name, amount, and category
- View all saved expenses
- Calculate total spending
- Save expenses using JSON file storage
- Load previously saved expenses when the program starts
- Validate numeric input

## Requirements
- Python 3
- No external libraries required

## How to Run
1. Download `CLI.py` from this repository.
2. Open a terminal in the folder containing the file.
3. Run:

```bash
python CLI.py
```
